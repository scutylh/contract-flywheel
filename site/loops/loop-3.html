01 · 人机分工

这一圈，人和 Agent 各自做什么

把软件开发拆成「需求 → 编码 → 测试 → 上线」四个动作。上栏是人类的工作，下栏是 Agent 的工作；占比条越短，说明这一步越不需要人工介入。

02 · 执行回放

全程无人工编码，人只看三样东西

点击横轴上的节点，聚焦查看该步骤；相邻步骤会淡出。左右滑动即可浏览全程。

03 · 交付的产品

准入关键词标红 · 审核结果同步业务组

法务要「独家 / 排他 / 最惠国」等准入关键词命中标红，业务组要同步看到审核结果。这一圈全程无人工编码：Agent 检索前两圈沉淀的管线、组件与约束，自主开发，另一组 Agent 评审，人工只看三样东西后一键确认。

为什么这一圈敢放手

站在资产之上提取管线来自圈 1、通知路由来自圈 2、写入约束来自双审记录——自主开发的前提是「没有新东西」。
准入条件显式化自治交付 = 复用已验证组件 且 改动 <150 行 且 回归全绿。条件写死在能力边界表里，Agent 自己判断、自己举证。
人退到闸门后人工不再逐行审代码，而是审三份证据：检索记录、Agent 评审意见、回归报告。40 秒确认，否决权仍在人手里。
04 · 三圈演变

演一遍：人逐步退出执行层

把三圈的分工矩阵连起来播一遍——人的占比条一圈比一圈短，到编码这一栏，人的部分彻底消失。
