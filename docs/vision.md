Agent = 代码 + 提示词。既然代码和提示词都可以由AI构建，那么agent也可以由AI构建。
一、各阶段目标
1. 长期目标：3-5 年内，大多数 Agent 的开发、运维、看护工作将由 AI Agent 自主完成，无需人工深度介入。
2. 中期目标：1-3 年内，常规 Agent 工作流实现 AI 自主开发交付，已验证的标准化流程可由 AI 完成审核。
3. 短期目标：0-1年内，在特定agent开发任务中完成AI开发的闭环，覆盖需求理解-开发-测试-上线部署的全流程。
二、分阶段里程碑
（一）短期：0-1 年，最小可用的闭环
- 核心目标：打通需求到开发的 AI 辅助链路，完成基础开发能力验证
- 关键里程碑
  1. 1-3 个月：实现会议纪要自动提取，生成开发 Issue，完成需求侧 AI 提效。
  2. 3-12 个月：Agent 可基于 Issue 自主完成对应工作流的代码 / 提示词开发，自动提交 MR，全部由人工审核后上线；同步建立渐进式迭代与反馈机制，持续沉淀 AI 可独立交付的 Issue 范围，明确对应难度、业务领域与交付成功率
- 人机职责
  - AI：需求结构化提取、工作流代码与提示词开发、自动提交 MR
  - 人：需求确认、MR 质量审核、结果反馈校准、边界规则定义
（二）中期：1-3 年，常规流程自主交付
- 核心目标：Agent 开发能力逐步深入，标准化流程实现开发 + 审核的半自治
- 关键里程碑
  1. 覆盖大多数常规业务流程（审批、查询、数据同步等）的 AI 自主开发、自动测试与自动上线
  2. 建立提示词回归测试体系，支持 Case 级自动化验证；已验证成熟、低风险的开发流程，逐步开放 AI 审核能力，替代人工完成常规 MR 校验
- 人机职责
  - AI：常规流程开发、测试回归、标准化 MR 审核、日常运维自愈
  - 人：高风险流程终审、异常问题处理、框架与规则迭代
（三）长期：3-5 年，全链路自主自治
- 核心目标：Agent 全生命周期 AI 自治
- 关键里程碑
  1. Agent 开发、调试、审核、运维、优化全链路由 AI 自主完成
  2. 实现系统变更自动适配、运行故障自动排查修复
- 人机职责
  - AI：全链路开发自治、运行看护、持续迭代优化
  - 人：顶层规则制定、合规治理、战略方向把控
三、主要的工作落地方向
1. 需求智能识别
  - 会议纪要 / 口语需求结构化提取
  - 缺失信息主动澄清，输出标准化需求单
2. 自主编码与测试
  - 共性组件框架下沉，Agent 聚焦业务流程本身
  - 系统数据接口标准化，支撑 AI 自动调用接口
3. 提示词迭代与回归
  - Case 级自动化回归测试体系
  - 提示词版本管理、灰度发布与回滚机制
4. AI 原生开发工具
  - 支持自然语言编排的流程设计平台
  - 一站式调试、回放、排障工作台
四、落地优先级
1. 第一优先级：完成高频系统连接器标准化，落地需求自动生成 Issue 功能，启动 Agent 基于 Issue 开发 MR 的能力验证
2. 第二优先级：建设回归测试体系，完善 AI 开发交付能力，同步搭建交付反馈与数据沉淀机制
3. 第三优先级：扩大 AI 自主开发覆盖范围，逐步落地成熟流程的 AI 审核能力，配套运行态自愈能力
