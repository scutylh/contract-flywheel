## 2. 演示场景：合同审核 Agent 的三圈飞轮

选合同审核场景的理由：同时踩在法务真实业务、JD 职责（需求提取 / 上下文组装 / 权限 / 人工确认 / 回放评估）、飞轮叙事三者的交叉点上，且复杂度足够拆圈。

**三圈的主角是"人机分工比例的变化"**：

| 圈 | 触发 | 人机分工 | 核心看点 |
|---|---|---|---|
| 圈 1 · 从 0 到可用 | 一段会议纪要 | 人 70% / Agent 30% | 需求结构化、人机协作编码、人+Agent 双审 |
| 圈 2 · 听懂反馈 | 负责人一句模糊反馈 | 人 50% / Agent 50% | Agent 主动反问澄清，收窄边界后再动手 |
| 圈 3 · 接近自治 | 新需求（准入关键词+发业务组） | Agent 95% / 人仅确认 | 检索历史代码与约束自主开发、Agent 评审 Agent、人工一键确认 |

### 圈 1 「从 0 到可用」
- **输入**：一段模拟的业务会议纪要（法务提出：合同审批靠人肉翻 PDF，金额/账期/付款条件靠肉眼核对，希望系统能提取关键信息）。
- **流程**：纪要 → Agent 结构化拆分为需求单 → 生成 Issue → 人机协作写出工作流代码（diff 上标注哪些行 Agent 写、哪些行人工改）→ 人工 + Agent 双审 → 上线。
- **上线能力**：合同关键信息提取（金额/账期/付款条件）→ 整理进现有流程表格 → 法务复核。
- **本圈沉淀**：需求单模板、信息提取 Skill、双审流程、第一条能力边界记录。

### 圈 2 「听懂反馈」
- **输入**：负责人一句反馈："要发送给对应的人进行提醒，分给不同的人。"
- **关键动作**：Agent **不直接动手**，先反问澄清——"对应的人是谁？'不同的人'指哪些角色？"——澄清后边界收窄为：本期只发法务。
- **上线能力**：账期自动提醒（发法务）。
- **本圈沉淀**：澄清式交互 Skill、通知组件、模糊反馈→确认边界 的评估用例。

### 圈 3 「接近自治」
- **输入**：新需求——准入条件关键词提取，审核结果发业务组。
- **流程**：Agent 检索历史代码、约束、组件信息 → 判断改动很小 → **自主完成开发**（无人工介入编码）→ 提交 MR → **另一组 Agent 评审**并给出意见（基本通过）→ 人工一键确认上线。
- **本圈沉淀**：能力边界表扩张（此类改动划入 Agent 自治区）、Agent 评审规则、自治交付成功率数据。

## 4. 技术架构

**决策：纯静态站 + 开发期 harness（可选）。不加常驻后端。**

```
contract-flywheel/
├── docs/
│   └── vision.md            # 原愿景文档（保留作附录入口）
├── harness/                 # 开发期 mini-harness（Python，可选）
│   ├── fixtures/            # 三圈的输入素材（会议纪要、反馈、需求）
│   ├── pipeline/            # 需求提取→Issue→开发→评审 的流水线
│   └── adapters/            # LLM 适配器（fixture 回放模式 / 真实 API 模式）
├── traces/                  # 三圈跑出的 trace JSON（步骤、输入输出、人工确认节点）
│   ├── loop1.json
│   ├── loop2.json
│   └── loop3.json
└── site/                    # 纯静态前端（单页）
    ├── index.html
    ├── css/
    ├── js/                  # trace 流式回放 + 飞轮动画
    └── assets/
```

- **harness**（Python）：fixture 驱动，真实跑三圈 pipeline，产出带时间戳的 trace JSON。跑得顺就用真跑出来的轨迹；跑不顺就按素材手工编排 trace，关键内容写实、次要处省略号——评审看的是叙事和判断力。
- **前端**：纯静态单页，读 trace JSON 做流式回放（逐条流出 Agent 执行轨迹）+ 飞轮动画。无框架或轻量框架（优先无依赖 vanilla JS，部署零风险）。
- **部署**：nginx 直发静态目录，无常驻服务，链接永远不会挂，评审随时打开效果一致。部署由于林海自行搞定。
- **诚实声明**：页面明确写出"Demo 轨迹由自研 mini-harness 跑出，LLM 调用使用录制 fixture 回放"——这本身呼应负责人"自研框架"的主张，是加分项。
